# ScholarLink

An academic scholarship website that brings together students, mentors, universities, and donors.

## Academic Context
- Course: Database Management Systems (CSCI2001), Asian University for Women (AUW).
- Semester: Spring 2025.
- Team: Five students.

## My Contribution
I worked with my teammates on the rich picture showing the platform's users and their relationships. I also contributed to the final project report.

## Features
- Search universities, programs, and scholarships.
- Create student, mentor, university, and donor accounts.
- Track scholarship applications and mentorship requests.
- Manage platform records through an admin dashboard.

## Technologies
PHP, MySQL, HTML, CSS, and XAMPP.

## Local Setup
1. Extract the project and copy `scholarhub` into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin/ and create a database named `scholarship_platform`.
4. Select the database and import `scholarhub/sql/scholarship_platform.sql`.
5. Open http://localhost/scholarhub/.
